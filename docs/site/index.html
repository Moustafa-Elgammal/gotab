Switch windows at the speed of thought.

GoTab is a keyboard-first window switcher for macOS — built from scratch in Go, with a thin AppKit shell.

macOS 12+ latest v0.3.1 GPL-3.0 universal arm64 · x86_64
Download for macOS View the source

Early release. The switcher works end to end in code and ships as a signed universal .app. Summon latency is measured (~15 ms, well inside budget); on-device verification of multi-Space behaviour, VoiceOver, and a clean-account launch is still in progress. Expect rough edges, and file what you find.

What it is

Hold ⌥, tap ⇥, and cycle through your windows in most-recently-used order — with a live thumbnail for each one. Release to switch. It is the switcher macOS never shipped, written as a native Go program rather than a scripting hack.

  • One flat panel, drawn in a single pass — no per-tile view hierarchy.
  • Most-recently-used ordering that only an actual focus change is allowed to reorder.
  • Thumbnails captured ahead of time and held in a bounded cache, so summon never blocks on pixels.
  • A rebindable hotkey — ⌥⇥ is just the default.
  • Enumeration joins CoreGraphics and Accessibility so windows on other Spaces are still listed.
  • Selecting one of those raises it by switching to its Space, or brings its app forward.
  • Windows that are genuinely gone leave the list within one rescan.
  • A filter for minimized / hidden / other-Space windows and a per-app blocklist.

Built around a few firm decisions

Every one of these was measured, not guessed — the numbers live in the project's DECISIONS log.

⌨️

Keyboard-first

Summon, cycle, and commit without the mouse. The hotkey callback lands in about 3 ms of a real keypress.

🖼️

Live thumbnails

ScreenCaptureKit previews, captured in the background and evicted by a fixed-capacity LRU. No leaked bitmaps.

🪟

Spaces-aware

A window on another Space is still in the list — and picking it switches to that Space and raises the real window.

🧠

MRU that behaves

Only an attention decision or a structural repair may reorder the list. A title change never moves a window.

🐹

Written in Go

All the logic is pure Go with a zero-allocation hot path; cgo and AppKit are a thin, humble shell at the edge.

🪶

Light on memory

The thumbnail cache is bounded and that bound is a number. macOS reclaims the rest; nothing grows without limit.

Getting started

Requires macOS 12 or newer, plus Go and the Xcode command line tools to build from source.

# build, package, install to /Applications, print the next steps
git clone https://github.com/Moustafa-Elgammal/gotab
cd gotab
./scripts/install.sh

Or grab GoTab-v0.3.1.zip from the releases page. The bundle is ad-hoc signed, so the first launch of a downloaded copy needs a right-click → Open (notarization is future work).

Two permissions, once:

  • Accessibility — to enumerate windows and raise the one you pick.
  • Screen Recording — for window titles and the live thumbnails.

GoTab asks for each when it first needs it and picks the grant up without a relaunch. Updates are check-only: gotab -check-update tells you a newer build exists; you download it yourself.

Built from scratch

GoTab has its own bundle ID and inherits nothing from any existing install — no preference migration, no license continuity, no borrowed code. A complete macOS window switcher is years of reverse-engineering undocumented platform behaviour, so the conclusions that cost the most to discover are written down in PLATFORM-LESSONS.md — every entry a platform fact, on its own terms.

Acknowledgements

GoTab is inspired by AltTab (lwouis/alt-tab-macos) — the idea that macOS deserves a fast, preview-driven window switcher, and the proof that it can be done well. AltTab is the reference point this project measures itself against and the reason the idea was worth pursuing.

GoTab shares none of AltTab's code. It is an independent implementation in Go, and any resemblance is in the goal, not the source. Both projects are released under the GNU General Public License v3.
