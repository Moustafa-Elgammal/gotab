# P1.5 — Selection resolver

**Branch:** feat/P1.5   **Phase:** 1   **Depends on:** P1.0

## Goal
The cursor: cycle, wrap, arrows — and survive the list changing underneath it.

## Files you may touch
- `internal/core/selection.go`
- `internal/core/selection_test.go`

## Signatures (exact)
```go
func (s *Selection) Set(o *Order, m *Model, index int)
func (s *Selection) Move(o *Order, m *Model, d Direction, wrap bool)
func (s *Selection) Reconcile(o *Order, m *Model)
```

## Behaviour that is not obvious
- **`Selection` carries both `Row` and `ID` on purpose.** The switcher stays open while windows open
  and close, so the list is rebuilt underneath the cursor. `Reconcile` re-finds the selected `ID`
  after a rebuild and only falls back to a position when the window is genuinely gone.
- When the selected window vanishes, `Reconcile` selects the entry now occupying the same index,
  clamped to the list — never jump to the front, which loses the user's place mid-cycle.
- `Move` with `wrap == false` clamps at both ends. With `wrap == true` it wraps in both directions.
- An empty `Order` leaves `Row == -1` and `ID == 0`. Every method must be safe on an empty list.
