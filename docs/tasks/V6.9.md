# V6.9 — permissions onboarding, the revoke → grant → recover loop

**Phase:** 6   **Needs:** a human at the machine, both TCC grants to toggle.
**Discharges:** the P4.3 `assumption` — the modal `NSAlert` and the full revoke→grant→recover loop
are written but unrun (the TTY fallback and the 750 ms poll are already exercised via a pty, D36);
and the P2.3b note — a grant revoked mid-run is untested.

## Goal

From a **revoked** state, `gotab -switch` shows the alert that names the missing grant and what it is
for, and granting it in System Settings brings the switcher up **without a relaunch** — the poll
(`CheckPermissions` every 750 ms, D36) picks it up. Both grants, and a mid-run revoke.

## Prerequisites

- `build/GoTab.app` (run the bundle, not `go run` — TCC identity).
- `tccutil reset Accessibility app.gotab` and `tccutil reset ScreenCapture app.gotab` to get to a
  clean revoked state (or `./scripts/uninstall.sh --purge`, which does both).

## Protocol

1. **Accessibility missing.** With Accessibility revoked, launch `gotab -switch` **from Finder** (no
   TTY, so the modal path — not the deep-link print). The `NSAlert` names Accessibility, says what it
   is for, and its button opens the right Privacy pane. Grant it there. Within ~1 s the switcher
   starts — **no relaunch**. (macOS may itself relaunch GoTab on the AX grant; the fresh process
   passing the gate is also acceptable — D36.)
2. **Screen Recording missing.** With SR revoked but AX granted, `-switch` runs (SR-missing is a
   one-line warning, not a block) but thumbnails and other-app titles are absent. Grant SR → within
   ~1 s thumbnails and titles appear, no relaunch.
3. **Mid-run revoke.** With the switcher running, revoke Accessibility. The next rescan/action
   surfaces the failure via `OnError` and the loop keeps running (does not exit); re-granting
   recovers it.
4. **Shell path (regression).** From a terminal, `gotab -switch` and `gotab -permissions` print the
   `x-apple.systempreferences:` deep links instead of stealing focus with a modal (already verified
   D36 — just confirm it still holds).

## Acceptance

- [ ] A mid-run revoke does not crash or exit the loop; re-grant recovers.
