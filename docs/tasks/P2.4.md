# P2.4 — Spaces: which Space is a window on, and which is current

**Phase:** 2  **Depends on:** P2.2  **Owns:** `space.h`, `space.m`, `space.go`

## Goal

Fill in `core.SpaceID`, which nothing populates today. D20 measured Accessibility failing to report a
second Chrome window and guessed "it is on another Space" without confirming it. **This is the task that
turns that guess into a number.**

## Files you may touch

- `docs/tasks/P2.4.md` (tick acceptance, record findings)

**Do not touch** `shim.h`, `shim.m`, `shim.go`, `window.go`, `internal/app/`, `cmd/gotab/`,
`docs/ROADMAP.md`, `docs/DECISIONS.md`.

## Contract

```go
// CurrentSpace returns the active Space, or 0 if it cannot be determined.
func CurrentSpace() core.SpaceID
// SpacesOf fills dst with the Space of each window id, index-aligned. 0 means unknown.
func SpacesOf(ids []core.WindowID, dst []core.SpaceID) ([]core.SpaceID, error)
```

## Notes

`SpaceID` 0 means **unknown** and must stay distinguishable from a real Space — `internal/core/api.go`
is explicit that SkyLight is private and may decline to answer. Never invent a Space.

SkyLight is a private framework (`/System/Library/PrivateFrameworks/SkyLight.framework`). Candidates:
`CGSCopyManagedDisplaySpaces`, `CGSGetActiveSpace`, `CGSCopySpacesForWindows`. Linking a private
framework may need `-F` in `CGO_LDFLAGS` and `CGO_LDFLAGS_ALLOW`; `dlopen`/`dlsym` is the fallback and
is more honest about the API being private. **If it cannot be done reliably, say so** — an accurate
negative is a successful task here (see AGENTS.md, "Scope discipline").
