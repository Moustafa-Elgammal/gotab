## Method

D8's instrument only reads its *own* process; `spike/procmem` applies the same three quantities to any
pid via `vmmap --summary`. Two things make or break the measurement:

1. **Timing.** `CG raster data` RESIDENT decays. Measured on this machine: a process holding 366.2 MB of
   CGImages reports 368.8 MB resident when sampled immediately after touching the pixels, and **6.4 MB**
   when sampled ~15 s later. Same process, same images. So sample *during and immediately after* a summon,
   and treat resident as a floor.
2. **`Physical footprint (peak)` is monotonic** and does not decay, so it survives the summon and is the
   honest number to quote. It resets when the process restarts.

Protocol:

```bash
go run ./spike/procmem -name AltTab -n 90 -every 1s    # then summon AltTab ~10x during the window
```

`-name` re-resolves the pid every sample: AltTab quits and relaunches itself when permissions are
granted, and a stale pid silently kills the whole session (it did, once).

## Preconditions the measurement is invalid without

- [ ] AltTab granted **Accessibility** *and* **Screen Recording**. Without Screen Recording it renders
      app icons instead of window thumbnails, so `CG raster data` stays empty and the number means nothing.
      This cannot be automated: TCC requires a human, and it blocks synthetic keystrokes too, so the
      summons must be pressed by hand.
- [ ] ~20 windows open across several apps
- [ ] The switcher visibly shows **window previews, not icons**

## Acceptance

- [ ] `CG raster data` is non-zero for at least one sample — proof thumbnails were actually captured
- [ ] Steady-state footprint and peak footprint recorded with the window count and AltTab version
- [ ] `docs/DECISIONS.md` gains an entry with the numbers and the version measured
- [ ] `docs/ROADMAP.md` P0.7 is `[x]` in the same commit

## Notes

If AltTab's thumbnails also sit at near-zero resident when idle, that is the D9 outcome and it should be
stated plainly: the memory goal would then be about *peak* and *virtual*, not steady-state resident, and
the gate criterion "steady-state RSS, 50 windows < AltTab's" needs rewording before P0.5 can use it.
