# P1.1 — Window/App model (struct-of-arrays)

**Branch:** feat/P1.1   **Phase:** 1   **Depends on:** P1.0 (frozen `api.go`)

## Goal
`Model` becomes usable: add, look up, update, remove, and record focus. Storage order is meaningless
(`Order` owns presentation), so removal is swap-with-last and stays O(1).

## Files you may touch
- `internal/core/model.go`
- `internal/core/model_test.go`

## Signatures (exact — other tasks are already coded against these)
```go
func NewModel(capacity int) *Model
func (m *Model) Len() int
func (m *Model) Row(id WindowID) (row int, ok bool)
func (m *Model) At(row int) Window
func (m *Model) Upsert(w Window) (row int)
func (m *Model) Remove(id WindowID) bool
func (m *Model) Touch(id WindowID) bool
func (m *Model) Reset()
```

## Behaviour that is not obvious
- `Upsert` with `w.Focus == 0` on an existing window **preserves** the stored `Focus`. A window that
  merely changed title must not lose its MRU position (PLATFORM-LESSONS §3).
- `Touch` assigns `nextFocus`, incremented first so no live window ever holds `Focus == 0`.
- `Remove` swaps the last row into the hole and **must fix `byID` for the moved row**. A stale index
  here switches to the wrong window; pin it with a test that removes from the middle.
- `Reset` keeps the allocated slices (`[:0]`) — the model is reused across summons.
