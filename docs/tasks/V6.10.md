# V6.10 — VoiceOver heard, not just written

**Phase:** 6   **Needs:** a human at the machine with VoiceOver (or Accessibility Inspector).
**Discharges:** the P5.2 `assumption` — the accessibility tree is written against the AppKit API and
has never been heard by a screen reader (an agent host has none — D41).

## Goal

Drive `gotab -switch` and `gotab -settings` with VoiceOver on and confirm the switcher is actually
usable without sight: every tile announced, the selection spoken on **every** cycle, the panel a
labelled container, and every settings control labelled.

## Prerequisites

- `build/GoTab.app`, Accessibility granted.
- VoiceOver (⌘F5). Accessibility Inspector (from Xcode) is an acceptable substitute for the element
  tree but cannot verify the *announcements* — use VoiceOver for those.

## Protocol — switcher

1. VoiceOver on. `gotab -switch`. Summon.
2. The panel reads as a container labelled **"Window switcher"** (group role).
3. Each tile is announced as **"&lt;title&gt;, &lt;app&gt;"**, button role.
4. Hold ⌥, press ⇥ repeatedly. On **every** cycle the newly selected tile is spoken (a high-priority
   announcement + a selection-changed notification — `panel_populate`, D41). Not just the first move;
   every one.
5. The tile frame VoiceOver highlights matches the visible tile (flipped-space frame is right).
6. Note: activating a tile is by releasing ⌥ (the modifier-release path) — VoiceOver "press" on a
   tile is a deliberate no-op (`panel.h` is frozen, no raise callback — D41). Confirm that is the
   behaviour, not a bug report.

## Protocol — settings

`gotab -settings` with VoiceOver on. Every control has a spoken label:

- [ ] the four filter checkboxes
- [ ] the blocked-apps text field
- [ ] the Appearance popup
- [ ] the Columns stepper
- [ ] the Thumbnail-cache stepper
- [ ] the hotkey recorder

## Acceptance

- [ ] Switcher: container label, per-tile "&lt;title&gt;, &lt;app&gt;", selection spoken on every
      cycle, correct frames.
- [ ] Settings: every control labelled.
- [ ] Findings appended to `docs/DECISIONS.md`; `docs/ROADMAP.md` Phase 6 row → ✅, P5.2's
      `assumption` marked discharged.

## If the selection is silent on later cycles

`g_a11y_last_*` debounces the announcement (D41); a bug there would speak the first move and go quiet.
That is a `panel.m` fix, back to P5.2 — with a note of exactly which cycle went silent.
