# P5.3 — Update mechanism (plain version check)

**Branch:** feat/P5.3   **Phase:** 5   **Depends on:** the carve (`internal/update/update.go` frozen:
`Check`, `Result`, `FeedURL`; `cmd/gotab -check-update` already calls `update.Check`)

## Goal

`internal/update` really checks a release feed. `Check` fetches `FeedURL`, decodes a small JSON
manifest, compares its version to the running one, and returns a `Result` saying whether a newer
build exists and where to get it. Pure Go, standard library only — no Sparkle, no cgo, no vendored
framework (D39). It does **not** download or install anything.

## Contract

- `check(ctx, current)`:
  - `http.Client{Timeout: 5 * time.Second}`, `http.NewRequestWithContext(ctx, GET, FeedURL, nil)`.
  - Non-200 → error. Body over a sane cap (e.g. 64 KiB via `io.LimitReader`) → error.
  - Decode into `manifest.go`'s struct. Missing/blank `version` or `url` → error.
  - Normalize `current` and `manifest.Version` (`version.go`), compare:
    - manifest strictly newer → `Result{Current, Latest, URL, Notes, Available: true}`.
    - equal or older → `Result{Current, Latest, URL, Notes, Available: false}`.
  - `current` that is not a comparable release — the literal `dev`, a bare `git describe` hash like
    `g1a2b3c4`, an empty string — → `Result{Current: current, Available: false}, nil` (no error;
    there is simply nothing to compare). `cmd/gotab` already short-circuits `version == "dev"` before
    calling, but `check` must not depend on that.
- Manifest shape (`resources/appcast/latest.json`), keep it minimal:
  ```json
  {
    "version": "0.2.0",
    "url": "https://github.com/Moustafa-Elgammal/gotab/releases/tag/v0.2.0",
    "notes": "Multi-monitor fixes and a faster first summon.",
    "min_macos": "12.0"
  }
  ```
  `min_macos` is carried for the future (a manifest that requires a newer OS than the host should not
  be offered); wiring that comparison is optional this round — if you skip it, say so in Findings.
- Version handling: accept a leading `v`, `major.minor.patch` with optional `-suffix` /
  `+build` which you may ignore for ordering. A missing patch is 0. Compare numerically field by
  field. Do not pull in a semver module — this is ~30 lines.

## Acceptance

- [x] `Check(ctx, "0.1.0")` against a manifest with `"version": "0.2.0"` →
      `Available == true`, `Latest == "0.2.0"`, `URL` set.
- [x] `Check(ctx, "0.2.0")` and `Check(ctx, "0.3.0")` against the same manifest → `Available == false`.
- [x] `Check(ctx, "dev")` and `Check(ctx, "g1a2b3c4")` → `Available == false`, nil error.
- [x] An unreachable `FeedURL`, a non-200, or a malformed body → non-nil error and a zero-ish
      `Result` (never a panic, never `Available == true`).
- [x] `go list -deps ./internal/update` names no third-party module (stdlib only).
- [x] `go run -ldflags "-X main.version=v0.1.0" ./cmd/gotab -check-update` pointed at a local
      manifest (temporarily set `FeedURL`, or serve `resources/appcast/latest.json` on
      `python3 -m http.server`) prints the "available" line for a higher manifest and "up to date"
      for an equal/lower one; a bad URL prints the one-line warning and exits 0.
- [x] `./scripts/check.sh` green.

Do the acceptance checks with a scratch `main` or a throwaway `_test.go` you delete before

## Findings

- **Split into three files as the contract asked.** `http.go` is the transport + orchestration:
  `GET FeedURL` with `http.Client{Timeout: 5s}` over the caller's context, non-200 → error, body
  read through `io.LimitReader(64 KiB + 1)` so an oversized feed is rejected rather than buffered.
  `manifest.go` is the struct + `decodeManifest`, which also rejects trailing data after the JSON
  object (`dec.Token() != io.EOF`) and blank `version` / `url`. `version.go` is `parseVersion` +
  `compare` — ~40 lines, no module.
- **Non-comparable `current` short-circuits before any I/O.** `parseVersion` returns `ok == false`
  for `""`, `"dev"`, and `git describe` hashes like `g1a2b3c4` (leading non-digit in the numeric
  core), and `check` returns `Result{Current: current}, nil` without building a request. `cmd/gotab`
  still guards `version == "dev"` itself, but `check` no longer relies on that.
- **Version ordering is the numeric triple only.** A leading `v`/`V` is stripped; `+build` then
  `-suffix` / `-N-gHASH` trailers are cut, so `v0.2.0-4-g1a2b3c4` and `0.2.0+ci` both reduce to
  `0.2.0`; a missing minor/patch is 0. Any non-integer in a present field makes the whole string
  uncomparable (returns `ok == false`), which on the manifest side is a hard error and on the
  `current` side is "nothing to compare".
- **`min_macos` is decoded, not enforced.** `manifest.MinMacOS` is parsed and trimmed but not
  compared against the host: that needs the running OS version, which would pull OS detection into
  this pure-stdlib package, and `update.Result` has no field to carry "blocked by newer-OS
  requirement". Deferred deliberately — a manifest that needs a newer macOS than the host would today
  still be offered. A follow-up, not a V6 row.
- **End-to-end run.** `resources/appcast/latest.json` served on `python3 -m http.server`, `FeedURL`
  redirected with `-ldflags -X …/internal/update.FeedURL=…`: `v0.1.0` → the "available" line with URL
  and notes; `v0.2.0` and `v9.9.9` → "up to date"; an unreachable feed → the one-line
  `update.checkFailed` warning on stderr and exit 0; `dev` → "development build — skipping". Scratch
  `_test.go` ran the full acceptance matrix (older/equal/newer, non-comparable, unreachable, non-200,
  malformed, blank version, blank url, oversize body, trailing data, garbage manifest version) plus a
  `parseVersion`/`compare` table; deleted before commit (D23).
- **Stdlib only.** `go list -deps -f '{{if .Module}}{{.Module.Path}}{{end}}' ./internal/update`
  names only this module; `go.mod` has no `require` block. Imports are `bytes`, `context`,
  `encoding/json`, `errors`, `fmt`, `io`, `net/http`, `strconv`, `strings`, `time`.
- **`assumption` → V6.11.** The check has only run against a local file. It has **not** run against a
  real published manifest over the network; `FeedURL` (`https://gotab.app/appcast/latest.json`) still
  has no host. The integrator turns this into a Phase 6 row and tags P5.3 `assumption` in
  `docs/ROADMAP.md`.
- **Out of scope (D39), not a V6 row.** Downloading the new build, verifying its signature, and
  relaunching in place. That needs a Developer ID signature + notarization the ad-hoc bundle does not
  have (D38). It is a separate future task.
- **For the integrator (V6.6).** `version.go`'s `parseVersion` / `compare` are pure and
  table-shaped — the natural home for the first committed `internal/update` tests when Phase 6
  writes them.
