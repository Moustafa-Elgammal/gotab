# P4.5 — Bundle packaging, ad-hoc codesign, install.sh

**Phase:** 4  **Depends on:** P2.1 (bundle/plist agreement, D17), P4.3 (onboarding text), P4.1 (the
prefs domain to purge)
**Owns:** `scripts/build.sh` (Info.plist + signing), `scripts/install.sh`, `scripts/uninstall.sh`,
and the no-flags default in `cmd/gotab/main.go`

## Goal

`build.sh` produces a `GoTab.app` that a person can install, launch, and remove cleanly. The
weak-SCK link and the `minos` / plist agreement check were done earlier this session (`27cd840`,
D17); this is the rest of the bundle.

## Contract

- `build.sh` writes a complete Info.plist (`plutil -lint` clean), signs the **bundle** ad-hoc, and
  verifies the signature (`codesign --verify --strict`). Version is split: `CFBundleShortVersionString`
  is a hand-bumped `SHORT_VERSION`, `CFBundleVersion` is `git describe`.
- `install.sh` builds, copies to `${GOTAB_APPS:-/Applications}`, verifies the installed copy's
  signature, and prints the permissions steps.
- `uninstall.sh` removes the app; `--purge` also removes the prefs plist and best-effort `tccutil
  reset`s both grants. Both honour `GOTAB_APPS`.
- `cmd/gotab` with no flags: the switcher when run from inside `.app` (a Finder double-click), a usage
  message from a shell.

## Findings

- **`spctl -a` on the ad-hoc bundle is `rejected`, and that is expected.** Gatekeeper only enforces
  that on a *quarantined* copy — one downloaded from a browser or AirDrop. A locally built,
  locally installed app carries no `com.apple.quarantine` xattr and launches normally despite the
  `spctl` verdict. A copy moved to another machine, or a future notarized release, is **V6.7** — the
  build comment and `install.sh` already say a public release needs a Developer ID and notarization.
- **No-flags default depends on the launch context.** `os.Executable()` ending in
  `.app/Contents/MacOS/` means Finder launched it and the user wants the switcher, not a usage string
  they cannot see. A shell invocation keeps the help text. Verified both ways.
- **`LSUIElement` + the settings window.** The bundle is an agent (no Dock tile); P4.2's settings
  window promotes to `NSApplicationActivationPolicyRegular` at runtime, which an `LSUIElement` app is
  allowed to do. Nothing in the plist needs to change for that.
- **`tccutil reset ScreenCapture app.gotab`** (not `ScreenRecording`) is the right service name;
  `Accessibility` is itself. Both returned "Successfully reset …" even when never granted — idempotent.
- **Two version strings.** `git describe` on this repo (no tags) is a bare short hash, and
  `CFBundleShortVersionString` is meant to be dotted numbers, so `SHORT_VERSION="0.1.0"` is the
  marketing string and `git describe` fills `CFBundleVersion` (and `-X main.version`) as the build id.
