## Goal
Rank windows against a typed query, deterministically.

## Signatures (exact)
```go
func Score(query, text string, positions []int) (score int, pos []int, ok bool)
func Search(m *Model, query string, dst []Match) []Match
```

## Behaviour that is not obvious
- **`Positions` index runes, not bytes.** Window titles are user text and contain multi-byte
  characters constantly; byte offsets make the UI highlight the wrong characters.
- Matching is subsequence-based and case-insensitive. Scoring must reward, in this order: an exact
  prefix, a match at a word boundary, and consecutive runs. Ties break by lower `Row` so the result
  is deterministic — a flapping order under an unchanged query is the bug to avoid.
- `Search` matches against **both** `Titles` and `AppNames`, keeping the better of the two scores.
- An empty query returns every row, in `Model` order, score 0.
- `Search` appends into `dst[:0]`. `Score` appends into `positions[:0]`.
