# V6.7 — ship the bundle, on a machine that is not the one that built it

**Phase:** 6   **Needs:** a genuinely clean macOS account, and a real macOS 12 host.
**Discharges:** the P4.5 `assumption` — a `minos 12.0` binary *launching* on macOS 12 (untested;
D17 is why this is not a formality — a wrong deployment target only ever fails on someone else's
computer), and a first launch from `/Applications` on a clean account (Gatekeeper on a quarantined
ad-hoc copy).

The self-verifiable half is **done** (D38): full `Info.plist` (`plutil -lint` clean, `LSUIElement`,
split `CFBundleShortVersionString` / `CFBundleVersion`), ad-hoc `codesign --verify --strict`, the
weak-SCK link, and the `install.sh` / `uninstall.sh` round-trip against a temp dir. This task is only
the parts that need another machine.

## Prerequisites

- A release build: either `./scripts/build.sh` locally, or the CI artifact from a `v*` tag
  (`GoTab-<tag>.zip`, V6.12).
- **Machine A:** a Mac on **macOS 12.0–12.2** (the weak-SCK floor; SCK arrives 12.3). A VM counts if
  it has a real display.
- **Machine B (or a fresh account on any supported Mac):** an account that has never run GoTab and
  never granted it anything.

## Protocol

1. **macOS 12 launch.** Copy the zip to Machine A, expand, `xattr -p com.apple.quarantine GoTab.app`
   to confirm it is quarantined, then right-click → Open (ad-hoc signing means Gatekeeper needs the
   explicit gesture — or `xattr -dr com.apple.quarantine`). It must launch, show the permissions
   onboarding, and — once granted — run the switcher. `otool -l` / the plist `LSMinimumSystemVersion`
   must *agree* and both say `12.0` (D17's fix derives them from one `MIN_MACOS`); this confirms a
   12.0 binary actually *runs* on 12.x, which D17 left untested.
2. **Clean-account first launch.** On Machine B, drag `GoTab.app` to `/Applications`, launch from
   there. Gatekeeper prompt → right-click → Open. The permissions flow appears (V6.9 is the detailed
   check of that loop; here it just has to *start*). No crash, no missing-framework dialog.
3. `gotab -check` from a terminal on each machine reports the grant state correctly.

## Acceptance

- [ ] `GoTab.app` launches and runs the switcher on a real macOS 12.0–12.2 host.
- [ ] `GoTab.app` launches from `/Applications` on a never-run account after the one-time Gatekeeper
      gesture.
- [ ] No dynamic-link failure (the weak-SCK link holds where SCK is absent).
- [ ] Findings appended to `docs/DECISIONS.md`; `docs/ROADMAP.md` Phase 6 row → ✅, P4.5's
      `assumption` marked discharged.

## Notes

`spctl` rejecting the ad-hoc bundle is expected (D38) — Gatekeeper only enforces assessment on a
