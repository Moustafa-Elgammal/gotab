# P2.3c — Join the two enumerations

**Branch:** main (Phase 2 is serial)   **Phase:** 2   **Depends on:** P2.2, P2.3a

## Goal

One switchable window list, built from both enumerations joined on `CGWindowID`. D20 established that
neither source is correct alone: CoreGraphics sees every window and cannot say which are switchable,
Accessibility says which are switchable and cannot see every window. Shipping either alone is a bug —
the CG list shows ~8x noise, the AX list silently cannot reach a window on another Space.

## Files you may touch

- `internal/platform/darwin/` (shim.h, shim.m, window.go)
- `cmd/gotab/main.go`
- `docs/ROADMAP.md`, `docs/DECISIONS.md`

## What has to be answered

1. **What lets a CoreGraphics-only window into the list?** It cannot be "has a title": D19 warned the
   title is empty for everything without Screen Recording, and a real untitled document window exists.
   Whatever the rule is, it has to be nameable, and windows it rejects have to be rejected for a reason.
2. **Does the rule recover D20's two misses** — Chrome's second window and Notion Calendar's — without
   readmitting the 52 entries D19 counted as noise?
3. **Where does this decision belong?** `core.Rules` is user preference and is frozen (P1.0). "Is this a
   window at all" is a platform fact. The boundary matters or the layering rots.

## Acceptance

- [x] two crossings, not 2N — the join costs one enumeration of each source, whatever N is
- [x] every titled layer-0 window is either in the list or excluded for a reason the code can name —
      51 exclusions across 3 named reasons, 0 of them titled
- [x] D20's two misses are both recovered (Chrome's second window, Notion Calendar)
- [x] a window's provenance is inspectable — `Enumerator.Origins`, shown as the FROM column
- [x] `./scripts/check.sh` green, purity gate included

Per D16 this task writes no tests.

## Notes

Provenance cannot live in `core.Window` — `internal/core/api.go` is frozen and adding a field is an
escalation, not an edit (AGENTS.md). It belongs beside the slice, in this package.

## Answer to question 1, since it took a wrong turn first

"Owning process is an application" alone is **not** enough: it produced a 44-window list, admitting 37
untitled auxiliary windows belonging to Chrome, Finder, Terminal, GoLand and System Settings. The rule
that works is that plus a title — and the title's TCC dependency is inherited, which D21 records along
with the `kCGWindowBounds` lead that could remove it.
