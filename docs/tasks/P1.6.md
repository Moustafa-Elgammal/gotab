# P1.6 — Tab-group model

**Branch:** feat/P1.6   **Phase:** 1   **Depends on:** P1.0

## Goal
A tab group shows as one entry. Decide which tab represents it.

## Files you may touch
- `internal/core/tabgroup.go`
- `internal/core/tabgroup_test.go`

## Signatures (exact)
```go
func Representative(m *Model, g TabGroupID) (row int, ok bool)
func IsRepresentative(m *Model, row int) bool
func GroupRows(m *Model, g TabGroupID, dst []int) []int
```

## Behaviour that is not obvious
- `TabGroupID == 0` means **not tabbed**. An untabbed window is always its own representative, so
  `IsRepresentative` returns true for it. `Representative(m, 0)` returns `ok == false` — group zero
  is not a group.
- The representative is the group member with the highest `Focus`; ties break by lowest `Row` so the
  choice is deterministic. The representative must not change when an unrelated window is focused.
- Election reads only `Groups` and `Focuses`. Do not filter, and do not consult `Rules` — P1.3 owns that.
- `GroupRows` appends into `dst[:0]`.
