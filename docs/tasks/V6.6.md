# V6.6 — the deferred table tests for the pure surfaces Phases 2–5 grew

**Branch:** verify/pure-surface-tests   **Phase:** 6   **Depends on:** every phase that deferred a
test under D16 / D23.

## Goal

D16 (generalised in D23) says new work writes no tests as it goes, in any phase, and Phase 6
collects them. The roadmap put one row here for that — titled "Phase 2/3 tests" — but Phases 4 and 5
also grew pure-Go packages (`internal/prefs`, `internal/i18n`, `internal/update`) whose only
verification so far is a scratch check in a session log. This task is the whole of that debt: the
`internal/core`-style table tests for **every pure surface Phases 2–5 added**, landing next to the
code, with `scripts/check.sh` staying green.

Scope is *pure* logic only. `internal/platform/darwin` stays the humble object
(docs/ARCHITECTURE.md) — its IPC/AppKit behaviour is V6.5's to verify by driving the app, and this
task does **not** unit-test it beyond the one function in it (`HotkeyDisplay`) that is pure string
formatting with no cgo in its body.

## Files touched (all new `_test.go`)

- `internal/prefs/prefs_test.go` — `Load` from a fake `Reader`, `Save` to a fake `Writer` and the
  round trip, the `-prefs Key=Value` parser (`Set`) across every type and every rejection, the
  out-of-range / wrong-type fallbacks in `Load`, and the `LayoutOpts()` / `Rules()` mappers
  (a dropped field there is a setting the switcher silently ignores).
- `internal/i18n/i18n_test.go` — the `normalize` tag table, `T`'s override→base→key fallback,
  `Sprintf` args, and `SetLocale` + `Load` against a `t.TempDir()` `<locale>.lproj/gotab.json`
  overlay (overridden key wins, omitted key falls through, missing file is a nil no-op, malformed
  file is the one error).
- `internal/update/version_test.go` — `parseVersion` (leading `v`, missing minor/patch,
  `-suffix` / `+build` / git-describe trailers, "dev" / "" / a bare hash → not ok) and `compare`.
- `internal/update/manifest_test.go` — `decodeManifest`: trims, ignores unknown fields, and rejects
  a blank `version` / `url`, trailing data, and bad JSON rather than reading them as "no update".
- `internal/update/check_test.go` — `check` end to end over `httptest`: available / up-to-date /
  older, the dev short-circuit making **no** request, and every error path (non-200, malformed
  manifest, a version that is not a release number, a body over `maxManifestBytes`, an unreachable
  host) returning an error and never `Available`. Overrides the package `FeedURL` var and restores it.
- `internal/app/loop_test.go` — the event loop's gesture handling (`handle`): summon → cycle →
  dismiss, `Cycle` before `Summon` is a no-op, only `Quit` stops the loop. Also holds V6.8's
  composite benchmark (see V6.8.md).
- `internal/platform/darwin/hotkey_test.go` — `HotkeyDisplay` chord → string table. The only
  darwin-package test; it adds a cgo test binary to the gate but no AppKit runtime dependency.
- `docs/ROADMAP.md`, this file.

## Notes

- **Why `internal/prefs` / `i18n` / `update` count as "V6.6" and not a new row.** Phase 6's preamble
  is "everything Phases 0–5 deferred, run once against the assembled app". The pure packages are part
  of "everything deferred" and have no other Phase 6 home — V6.7/V6.9 (machine/human) and
  V6.10/V6.11 (VoiceOver / live host) do not cover their unit logic. Folding them in here rather than
  minting V6.13 keeps the phase's row count honest about how much is actually left.
- **Comment drift spotted, not fixed here.** `internal/prefs/prefs.go` and its `doc.go` still say the
  filter fields are "schema-only until a later Phase 4 task" and "the event loop does not consult
  Rules yet" — P4.4 (D37) wired both. A docs-only follow-up; out of scope for a test-only task.
- The `internal/i18n` tests mutate process-global locale state (`SetLocale`/`Load` are startup-only
  by contract, so the package offers no reset); every test that touches it restores `SetLocale("en")`
  via `t.Cleanup`.
