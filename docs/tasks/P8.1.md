# P8.1 — Menu-bar status item

**Phase:** 8   **Depends on:** the switcher run loop (`runSwitcher`), `gt_settings_open` (P4.2)
**Owns:** `internal/platform/darwin/menubar.h`, `menubar.m`, `menubar.go`, and the wiring in
`cmd/gotab/main.go`'s `runSwitcher`.

## Goal

Give a Finder-installed GoTab a surface. It is `LSUIElement` — no Dock tile, no app menu — so before
this, the only way to open Settings or quit was a `gotab -flag` in a terminal (D52). One menu-bar
status item fixes that.

## Files you may touch

- `internal/platform/darwin/menubar.{h,m,go}` — new, yours alone
- `cmd/gotab/main.go` — the `runSwitcher` wiring and the `openSettingsProcess` helper
- `docs/tasks/P8.1.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`

**Do not touch** `shim.{h,m,go}`, `internal/core/api.go` (frozen), `panel.h` (frozen),
`settings.{h,m,go}` (P4.2 — call it, don't change it), `internal/app/`.

## Contract

```
gt_status gt_menubar_install(const char *title);  // idempotent; "" title omits the header row
void      gt_menubar_remove(void);                // safe when nothing installed, safe twice
extern void goMenubarSettings(void);              // -> Go: launch `gotab -settings`
extern void goMenubarQuit(void);                  // -> Go: cancel ctx (same as ^C)
```

- One `NSStatusItem` (`NSVariableStatusItemLength`), a `macwindow.on.rectangle` template symbol
  (falls back to `rectangle.on.rectangle`, then a `"⌥⇥"` title). Menu: a disabled `GoTab <version>`
  header, separator, **Settings…**, separator, **Quit GoTab**.
- **Settings…** must not open the window in-process: `gt_settings_open` flips the app to Regular
  activation policy, and the switcher is Accessory. Spawn `gotab -settings` instead — it is the
  standalone entry point and owns its own window / run loop / policy.
- **Quit GoTab** cancels the switcher's `ctx`; the existing shutdown goroutine tears everything down.
- A status item works under Accessory policy, so this does not change the switcher's policy.
- Installed via `OnMain` before `RunLoop`; `RemoveMenuBar` in the shutdown goroutine.

## Notes

Settings changed via the spawned window take effect in the running switcher **on its next launch**,
same as `gotab -settings` from a terminal always has. Live re-read of the filter fields would be a
separate change (post a `Rescan` after a save); not in scope here.
