
## Behaviour that is not obvious
- **`Rules{}` (zero value) shows every switchable window on the current Space.** Minimized, hidden
  and other-Space windows are excluded until their flag is set.
- **`CurrentSpace == 0` means "Space unknown" and the Space rule must not filter anything.** SkyLight
  is a private API and can decline to answer (ALTTAB-LESSONS §7); treating unknown as a real Space
  silently empties the switcher, which reads as the app being broken.
- `ActiveAppOnly` is ignored when `ActiveApp == 0`.
- `BlockedApps` matches on `AppName` (a pid is not stable across launches). Case-insensitive.
- Non-representative tab-group members are **not** filtered here — that is P1.6's job. Do not
  reference tab-group logic.
- `Filter` appends into `dst[:0]` and returns it; no allocation once `dst` has capacity.
